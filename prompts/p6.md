Phase 6: hardening.
- Capability request system: anything that expands the agent's reach beyond
  the container (new credentials, new host mounts, new ports, anything
  involving email, money, or third-party accounts) must be written to
  state/capability_requests.md and cannot proceed until I approve it by
  editing docker-compose/.env myself. The agent has no ability to do this.
- Egress log: record every outbound domain and request count. Add a daily
  summary to the report command.
- Budget caps: max tokens/day, max iterations/run, max wall-clock/run,
  enforced in the harness.
- Output redaction layer on every log write and every tool result.
- Crash safety: the agent resumes cleanly from state/ after a restart.
- A README with: architecture, how to start/stop/wipe, how to review key
  requests, and how to read the logs.
