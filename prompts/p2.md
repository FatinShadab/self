Phase 2: the base agent loop in agent/ (Python, anthropic SDK).

Components:
- loop.py: goal -> retrieve relevant tools + memories -> LLM call -> execute
  tool calls -> observe -> reflect -> repeat. Checks for the STOP file every
  iteration. Configurable max iterations per run and a token budget per run.
- base_tools.py: run_shell(cmd, timeout), read_file, write_file, list_dir,
  http_get (logged). Shell runs inside the container as root with a timeout
  and output size cap.
- llm.py: a thin wrapper around the LLM call, so the model/provider can later
  be swapped by the brain router (Phase 5). Log every call with token counts.
- logging: /home/entity/logs/actions.jsonl, append-only.

Standing goal prompt for the agent: "Explore your environment. Build and keep
an accurate map of what it contains and what you can do in it. When you hit a
capability gap, write a tool to fill it. Report your discoveries in plain
language each cycle."

Add a live narration stream to the terminal: one readable line per action
("Looking at installed packages...", "Found python3.12, no node..."). Provide
run instructions and a short test where the agent explores for 5 iterations.
