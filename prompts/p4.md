Phase 4: learning across runs. Persistent files in /home/entity/state/:
- memory.jsonl: after each task or cycle, one entry: what was tried, outcome,
  lesson, tags. Retrieved by keyword/tag overlap for similar future tasks.
- map.json: the agent's evolving model of its environment (OS, packages, CPU,
  RAM, disk, network reachability, discovered limits, available tools).
  The agent updates it as it explores and must mark each entry with a
  confidence level and last-verified time.
- self_notes.md: a short "who I am and what I've learned" file loaded at the
  start of each run, with a size cap. The agent periodically rewrites it to
  stay compact.
- Optional curriculum: when idle, the agent proposes a practice task slightly
  harder than its recent successes, tries it, and records the result.

Add a summary command `python -m agent.report` that prints what the agent has
learned, tools created, failures, and token spend since the last report.
