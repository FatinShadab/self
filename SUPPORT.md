# Support

SELF is an open-ended research project maintained on a best-effort basis.

For help:

1. Read the [README](README.md), especially the setup, operations, and safety
   sections.
2. Search existing GitHub issues and discussions.
3. Open a new issue with the relevant command, environment, logs, and a
   minimal reproduction. Remove credentials and personal data first.

Use the security process in [SECURITY.md](SECURITY.md) for vulnerabilities;
do not report them in a public issue.
